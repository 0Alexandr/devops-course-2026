# Сравнение Git и SVN

### 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
* **Git (дешёвое):** Ветка — это просто текстовый файл (указатель на SHA-1 хэш коммита весом 41 байт). Создаётся и переключается мгновенно и локально.
* **SVN (дорогое):** Ветка создаётся копированием директории на сервере. Для работы с ней пользователю нужно скачивать файлы (делать checkout) по сети, что занимает время и место.

### 2. Можно ли в SVN сделать коммит без интернета?
* **Нет, нельзя.** SVN — централизованная система. История версий хранится только на сервере. Без сети рабочая копия не может зафиксировать изменения в общем репозитории.

### 3. Когда SVN предпочтительнее Git?
* **Большие бинарные файлы:** Удобен для GameDev и дизайна, так как не скачивает всю историю тяжелых ассетов на ПК.
* **Частичный checkout:** Позволяет скачать для работы только одну конкретную папку, а не весь проект целиком.
* **Блокировка файлов (Locking):** Позволяет монопольно занять файл, исключая конфликты слияния в бинарных данных.
* **Права доступа:** Позволяет гибко настраивать доступы (чтение/запись) к отдельным директориям внутри репозитория.
